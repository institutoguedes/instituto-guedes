# Política de Segurança

Este sistema vai lidar com dados sensíveis (fé, crianças, famílias assistidas), protegidos pela LGPD. Segurança é prioridade.

## Como reportar
**Não abra issue pública.** Use a aba **Security → Report a vulnerability** (reporte privado do GitHub) deste repositório.

Inclua: descrição, passos para reproduzir, impacto e sugestão de correção, se houver. Responderemos assim que possível e manteremos você informado.

## Princípios
- Nenhum segredo no código; use variáveis de ambiente.
- Isolamento por igreja: uma igreja nunca enxerga dados de outra.
- Regras críticas (cadastro, estoque, permissões) ficam em código, não em IA.
- Menor privilégio e permissões por perfil.
- Dependências monitoradas pelo Dependabot.
